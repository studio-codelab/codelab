Adresse mail
Adresse mail
L'adresse rattachee a ton compte.
 
Un code a six chiffres est envoye a cette adresse pour verifier que tu la releves vraiment. Cette verification ne remplace pas le second facteur et n'ouvre aucune session : elle atteste seulement que l'adresse est la tienne.
Aucun serveur d'envoi n'est configure sur ce serveur : la verification par mail est indisponible pour le moment.

Session

Securite
Double authentification
Un code a six chiffres, en plus du mot de passe, a chaque connexion.
 
Le mot de passe est un secret unique : s'il fuit, il donne l'execution de commandes sur cette machine. Le second facteur exige en plus ton telephone. A activer avant d'exposer ce panneau au-dela de ton reseau.
1. Scanne ce code avec ton application d'authentification.
Ou saisis la cle a la main :
2. Saisis le code affiche par l'application pour confirmer. Rien n'est enregistre tant que ce code n'est pas valide — une cle mal recopiee ne peut donc pas t'enfermer dehors.
Pour desactiver, saisis un code valide : une session volee ne doit pas pouvoir retirer le second facteur.
Cles d'acces
Cles d'acces (passkeys)
Se connecter avec l'empreinte ou le code de son appareil.
 
Une cle d'acces remplace le mot de passe et le code a six chiffres : l'appareil prouve la possession, et l'empreinte (ou le code de l'appareil) prouve que c'est bien toi. Rien a retenir, rien a recopier — et rien a hameconner, puisque la cle ne signe que pour le domaine qui l'a enregistree.
Pour la reconnaitre dans la liste, le jour ou tu en auras plusieurs.
Serveur
Exposition
L'etat des reglages qui comptent si ce panneau devient accessible depuis internet.
Ces trois reglages se posent au demarrage du service, pas ici : les activer depuis cette page pendant que tu es connecte en clair te deconnecterait sur-le-champ. Ils se resolvent dans l'ordre — le premier fait le travail, les deux autres sont une variable chacun. Les cles d'acces dependent aussi du premier : le navigateur refuse WebAuthn en clair.
Adresse publique
L'adresse par laquelle ce serveur est joignable depuis internet.
 
Tant qu'elle n'est pas declaree, le panneau ne propose pas de rendre une application publique : sur un serveur que personne d'autre ne peut joindre, « publique » ne partagerait rien — cela retirerait seulement l'authentification. Une application deja publique n'est pas touchee, et peut toujours etre refermee.
Elle se declare a la main : le panneau ne peut pas savoir si le port 443 de ta box est ouvert, si ton tunnel tourne, ni quel nom de domaine y mene. La renseigner, c'est dire « j'ai fait le necessaire ».
Vide = serveur prive, joignable seulement depuis ton reseau.
Cette adresse est fixee par APP_MANAGER_PUBLIC_URL dans le compose : elle se modifie la-bas.
Categories
Categories du hub
Des tiroirs pour ranger les projets sur la page d'accueil.
Une categorie ne donne aucun droit et ne change rien au deploiement : elle regroupe les projets dans le hub, dans l'ordre de cette liste. Un projet sans categorie apparait a la fin, sous « Autres ». Choisis la categorie d'un projet dans sa fiche, onglet Configuration.
E-mail
Serveur d'envoi (SMTP)
Par ou sortent les mails de CodeLab.
 
Trois choses en dependent : les alertes quand une application tombe, les codes de verification des adresses mail des comptes, et l'inscription libre — qui reste fermee tant qu'aucun serveur n'est configure, faute de pouvoir verifier une adresse.
Laisse vide pour conserver celui deja enregistre. Gmail exige un mot de passe d'application, pas ton mot de passe habituel.
Le seul controle qui vaille : un serveur qui accepte la connexion peut encore refuser d'expedier. Vide, le test part aux destinataires des alertes.
Ces reglages vivent dans le bloc codelab-alertes de credentials.env : le capteur d'alerte de Dagster lit le meme serveur d'envoi. Une seule configuration pour toute la stack.
Alertes
Alerte par mail
Un mail quand une application tombe, un autre quand elle revient.
 
Le panneau redemarre tout seul une application qui plante. Il abandonne au bout de 5 tentatives en 10 minutes — c'est a ce moment-la que le mail part, pas au premier soubresaut. Un second mail signale le retour a la normale.
Separes par des virgules.

Compte

Identite
8 caracteres au minimum. La personne n'est pas deconnectee : sa session en cours reste valable jusqu'a ce qu'elle la ferme.
Le nom du compte ne se change pas : il identifie la personne partout — dans ses cles d'acces, dans le journal des acces, dans la liste des projets autorises. Pour renommer quelqu'un, cree un compte et supprime l'ancien.
Projets autorises
L'autorisation ne compte que pour les projets prives : un projet public reste ouvert a tout le monde, y compris sans connexion.
