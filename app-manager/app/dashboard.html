Connexion CodeLab

        
L'application reçoit l'identité signée des personnes connectées
          (X-CodeLab-Auth, vérifiable avec CODELAB_SSO_PUBLIC_KEY). Les modules
          codelab_auth.py et codelab-auth.js, posés par
          codelab new, font la connexion silencieuse : session de l'application, sinon
          CodeLab, sinon son formulaire habituel. Après la connexion, le visiteur revient dans
          l'application.

Envoi des mails

    

      

        Serveur d'envoi (SMTP)
        
Par où sortent les mails de CodeLab : alertes, invitations, codes.

      

       

      
Les mails passent par Mailpit, qui les relaie par ce serveur. Un compte Gmail avec un mot de passe d'application suffit.

      

        

          

        

          

      

      

        

          

            
            
            
          

        

          

      

      

        
        
Laisse vide pour conserver celui déjà enregistré. Gmail exige un
          mot de passe d'application, pas ton mot de passe habituel.

      


      

        
      

      

      

    

  


  

    
Alertes

    

      

        Alerte par mail
        
Un mail quand une application tombe, un autre quand elle revient.

      

       

      
Un mail quand une application ne redémarre plus (5 échecs en 10 minutes), un autre quand elle revient.



      

      

      

      

        
        
        
Séparées par des virgules. Elles reçoivent les alertes de toutes les applications.

      

      

        
        
      

      

      

    

    

      

        Si le serveur entier tombe
        
Un service extérieur te prévient quand le serveur se tait.

      

       


      
Quand le serveur se tait (coupure, panne), un service extérieur gratuit te prévient. Sur healthchecks.io : un « check » de 5 minutes, puis colle ici son adresse de ping.


      

        
        
        
Vide = désactivé. L'adresse est appelée une fois à l'enregistrement,
          pour vérifier qu'elle répond.

Activer Face ID ?

    
La prochaine fois, connecte-toi d'un regard : ni mot de passe, ni code à
      recopier. Tu pourras le retirer à tout moment dans Paramètres > Sécurité.

  

  

    
    
  







  
Régler l'envoi des e-mails

    
Aucun serveur d'envoi (SMTP) n'est réglé. Sans lui, impossible d'inviter quelqu'un
      ou de créer un compte : chacun reçoit son invitation et ses codes de connexion par e-mail.
      Les alertes partent aussi par là.
